Project and data

ES 335 final project by Tagalpallewar Abhishek Prashant (24110364) and Siddhantkumar Vinay Thute (24110373). We estimate next-month default for existing credit-card accounts, then study thresholds under asymmetric assumed costs.

The UCI Default of Credit Card Clients dataset contains 30,000 Taiwan accounts, 23 predictors and one binary target. One row is one account; roughly 22.12% defaulted. Inputs include credit limit, demographics, repayment statuses, bill amounts and payment amounts.

Setup and run

Use Python 3.11 or newer. Run from the repository root. The first script downloads the UCI .xls file and saves a CSV copy. If that URL is unavailable, download from UCI and save a CSV with the original column names at data/raw_credit_default.csv.

python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python src/01_inspect_data.py
python src/02_split_data.py
python src/train_baselines.py
python src/analyze_baselines.py
python src/calibrate_and_optimize.py
python src/train_ensembles.py
python src/evaluate_all_models.py
python src/cost_optimizer.py
python -m http.server 8000 --directory docs

Open http://localhost:8000/. The fixed stratified split is 70/15/15 with seed 42. Row-level category cleaning occurs before the split; learned scaling and encoding fit on training folds only.

Files to check

  • src/: data audit, fixed split, preprocessing, models, calibration and cost optimizer.
  • data/: raw CSV and exact train, validation and test CSVs.
  • results/: full validation metrics, probabilities, selected hyperparameters and one-time test report.
  • docs/assets/: figures and the simulator’s test label/probability JSON.

At the stated assumed costs, HistGradientBoosting had validation loss $4,187,500 at threshold 0.1304. Validation selected threshold 0.135. On test, PR-AUC was 0.5596 and ROC-AUC was 0.7798; assumed loss was $4,239,000 versus $6,677,000 at 0.50.

The workflow uploads this docs/ folder on site changes. Full setup details are in the repository README.

Limits and disclosure

Costs are hypothetical; the dataset does not record actual losses or intervention effects. It describes Taiwan accounts in 2005, so transfer to current populations needs testing. Group fairness has not been established.

Google Gemini and OpenAI Codex/ChatGPT assisted with Python pipeline scaffolding, diagnostic plotting scripts, static website layout/styling, and the original halftone hero illustration (generated via built-in ImageGen; prompt saved). Both team members independently verified all mathematical derivations, split boundaries, saved metrics, and literature citations against the raw code and data.

The visual direction was inspired by GoShuin — Every stamp, a memory. Its artwork and interface assets were not reused.
